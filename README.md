## Metatah Theme 1 – Digital Invitation

Metatah adalah upacara potong gigi atau pengikiran gigi tradisional bagi umat Hindu di Bali yang menandai peralihan seorang anak menuju masa dewasa.
---

## 💻 Teknologi yang Digunakan
Website ini dibangun menggunakan:
- HTML → struktur halaman  
- CSS → desain dan tampilan visual  
- JavaScript → interaksi pengguna (belum sampai database)

---

## ✨ Fitur Utama

- 💌 Tampilan undangan digital modern  
- 📱 Responsive design (desktop, tablet, dan mobile)  
- 🎨 Desain elegan dengan nuansa budaya Bali  
- 📍 Informasi acara  
- 🖼️ Gallery foto  
- 🕒 Informasi waktu acara  
- 🎵 Background music untuk meningkatkan suasana    
- ✨ Animasi simpel 

## 📦 Tujuan Pengembangan

Project ini dibuat sebagai:
- Undangan digital cepat saji
